# Report Assets

일일 리포트에서 사용하는 이미지·도표 자산을 날짜별로 관리하기 위한 디렉터리입니다.

```text
assets/
└── YYYY-MM-DD/
    ├── ai-01.*
    ├── robotics-01.*
    ├── space-01.*
    └── markets-01.*
```

## Asset Policy

- 공식 기관/기업이 제공하고 사용 조건을 확인할 수 있는 이미지 또는 재사용이 허용된 자료를 우선합니다.
- 원본 출처와 라이선스/크레딧 정보를 리포트 또는 자산 메타데이터에 기록합니다.
- 기사 사이트의 저작권 이미지를 임의로 복제하지 않습니다.
- 적절한 이미지 권리를 확인할 수 없으면 외부 원문 링크를 제공하고 저장소에는 복사하지 않습니다.
