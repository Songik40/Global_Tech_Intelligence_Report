## Why remote instead of copied binary?

현재 GitHub 연결에서는 외부 웹 이미지의 바이너리 파일을 직접 저장소로 복사하는 경로가 제한된다. 따라서 재사용 조건이 검증된 원본만 원격 임베드하고, 라이선스 메타데이터를 저장소 안에 영구 기록한다. 직접 만든 도표는 실제 SVG 파일로 저장한다.
