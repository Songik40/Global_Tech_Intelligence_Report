# Robotics & Autonomy — Trend Tracker

_Last updated: 2026-08-28_

## Current Direction

로봇·자율주행은 **기술 데모 → 실제 배치 → 신뢰성·경제성 검증** 단계로 이동하고 있다.

## Key Drivers

- 멀티모달 모델과 로봇 제어
- 실제 환경 행동 데이터
- 액추에이터·배터리·센서 비용
- fleet learning
- 안전성과 운영 신뢰성

## Recent Evidence

- [2026-08-28](../reports/2026/08/2026-08-28.md): Reuters의 중국 휴머노이드 산업 조사는 하드웨어 발전과 실제 공장 작업 능력 사이의 간극을 보여준다.

## Major Players / Systems

중국 휴머노이드 업체, 글로벌 산업용 로봇 기업, 자율주행 서비스 사업자, 자동차 제조사, foundation robotics 연구그룹.

## Technical Bottlenecks

- 장시간 무개입 작동
- 정밀 manipulation
- 새로운 작업에 대한 일반화
- 실패 복구
- 안전 검증
- 작업당 총비용

## Contradicting Signals

투자·기업 수·데모 능력은 빠르게 증가하지만, 반복 가능하고 수익성 있는 실제 작업 데이터는 상대적으로 부족하다.

## Commercialization Metrics

- 작업 성공률
- intervention rate
- mean time between failures
- 시간당 비용
- 새로운 작업 학습 시간
- 실제 유료 고객 배치 수

## 30–90 Day Watchlist

- 공장 POC가 유료 배치로 전환되는지
- 실제 운영시간 데이터 공개
- 로봇 가격 하락이 소프트웨어·정비 비용을 상쇄하는지
- 자율주행 상업 운행 지역 확대

## Working Thesis

> Physical AI의 승자는 가장 인상적인 데모보다 **신뢰 가능한 실제 행동 데이터와 경제성**을 먼저 확보하는 쪽일 가능성이 높다.
