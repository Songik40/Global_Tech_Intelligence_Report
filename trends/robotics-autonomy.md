# Robotics & Autonomy — Trend Tracker

_Last updated: 2026-08-30_

## Current Direction

로봇·자율주행은 **기술 데모 → 실제 배치 → 신뢰성·경제성 검증 → 지역 생산·정책적 선별** 단계로 이동하고 있다.

## Key Drivers

- 멀티모달 모델과 로봇 제어
- 실제 환경 행동 데이터
- 액추에이터·배터리·센서 비용
- fleet learning
- 안전성과 운영 신뢰성
- 지역 산업구조와 실제 수요에 맞는 배치
- 대량생산·현지조달·서비스 네트워크

## Recent Evidence

- [2026-08-30](../reports/2026/08/2026-08-30.md): Minth와 AGIBOT가 세르비아 Šabac에서 휴머노이드 로봇 양산을 시작했다. Physical AI 경쟁이 중국 내 생산에서 유럽 인접 지역 생산거점과 서비스망 구축으로 확장되는 신호다.
- [2026-08-29](../reports/2026/08/2026-08-29.md): 중국 NDRC가 로봇 산업의 지역 적합성, 질서 있는 발전, 실제 환경 데이터와 신뢰성 검증을 강조하면서 '무조건적 확장'보다 실배치 중심의 정책 신호가 강화됐다.
- [2026-08-28](../reports/2026/08/2026-08-28.md): Reuters의 중국 휴머노이드 산업 조사는 하드웨어 발전과 실제 공장 작업 능력 사이의 간극을 보여준다.

## Major Players / Systems

중국 휴머노이드 업체, 글로벌 산업용 로봇 기업, 자율주행 서비스 사업자, 자동차 제조사, foundation robotics 연구그룹, 지역 제조 파트너.

## Technical Bottlenecks

- 장시간 무개입 작동
- 정밀 manipulation
- 새로운 작업에 대한 일반화
- 실패 복구
- 안전 검증
- 작업당 총비용
- 실제 환경 데이터의 품질과 규모
- 계획 생산능력을 실제 유료 수요로 전환하는 속도

## Contradicting Signals

생산능력과 투자·기업 수는 빠르게 증가하지만, 반복 가능하고 수익성 있는 실제 작업 데이터는 상대적으로 부족하다. 공장 오픈과 `planned capacity`는 상용화 성과가 아니며 실제 고객 인도량과 가동률을 별도로 봐야 한다.

## Commercialization Metrics

- 작업 성공률
- intervention rate
- mean time between failures
- 시간당 비용
- 새로운 작업 학습 시간
- 실제 유료 고객 배치 수
- 실기기 데이터 수집량과 품질
- 월별 생산량·가동률·현지조달률

## 30–90 Day Watchlist

- 세르비아 생산거점의 실제 월별 생산·인도량
- 중국 지방정부의 신규 로봇 지원정책 변화
- 공장 POC가 유료 배치로 전환되는지
- 실제 운영시간 데이터 공개
- 신뢰성·안전성 평가 기준의 공식화
- 자율주행 상업 운행 지역 확대

## Working Thesis

> Physical AI의 승자는 가장 인상적인 데모보다 **신뢰 가능한 실제 행동 데이터, 지역별 적용 적합성, 대량생산·서비스 능력, 경제성**을 먼저 연결하는 쪽일 가능성이 높다.
