# Image Policy

## Principle

뉴스 기사에 포함된 사진을 단순 복사하지 않는다. 이미지도 텍스트 출처와 동일하게 **출처·저작자·라이선스·대표성**을 검증한다.

## Preferred media

1. CC0 / Public Domain
2. 명시적 Creative Commons 라이선스
3. NASA 등 재사용 정책이 명확한 공공기관 자료
4. ESA의 명시적 CC 라이선스 자료
5. 기업 공식 media kit 중 재사용 조건이 확인되는 자료

## Not copied by default

Reuters, AP, Getty 등 기사 페이지의 저작권 사진은 별도 사용권이 확인되지 않으면 저장소에 복제하지 않는다.

## Remote embeds

현재 연결 환경에서 외부 바이너리 파일을 GitHub 저장소로 직접 복사하는 경로가 제한되는 경우, 라이선스가 검증된 Wikimedia Commons 등의 **원본 파일 URL을 Markdown에 직접 임베드**한다. 이 경우 `assets/YYYY-MM-DD/README.md`에 다음을 기록한다.

- 원본 파일 페이지
- 저작자
- 라이선스
- 원본/대표 이미지 여부
- 수정 여부

## Representative images

정확한 당일 사건 사진이 아니라 분야를 설명하는 대표 이미지를 쓸 경우 캡션에 반드시 **Representative image only**라고 적는다. 대표 이미지는 해당 사건의 증거로 사용하지 않는다.

## Repository-created graphics

데이터 흐름·공급망·시장 스냅샷 같은 설명용 도표는 SVG로 직접 생성해 저장소에 보관한다. 도표에 들어간 데이터는 해당 리포트의 출처를 따라간다.
