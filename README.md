## Source Standard

가능하면 공식 기업·기관 발표, 규제기관·정부·논문 등 **1차 출처**를 먼저 확인합니다. Reuters·AP 등 고신뢰 매체는 독립 교차검증과 맥락 보강에 사용합니다. 자세한 기준은 [Source Ranking](methodology/source-ranking.md)을 참고하세요.

## Image Standard

저작권이 불명확한 기사 사진은 저장소에 복제하지 않습니다. 재사용 조건이 명확한 Wikimedia Commons, NASA/ESA 공개 자료 등을 사용하고 저작자·라이선스·원본 페이지를 기록합니다. 현재 GitHub 연결에서 외부 바이너리 파일을 직접 복사하는 경로가 제한되는 경우에는 **검증된 원본 이미지를 Markdown에 원격 임베드**하고, `assets/`에 라이선스 메타데이터를 남깁니다. 직접 만든 도표는 SVG로 저장소에 보관합니다.
